# 反立场造爆点（reverse-angle）

别人都说「这样才对」时，你站到对面说「不一定、其实是反的」，还说得有道理、有证据——观众因为「咦，跟我想的不一样」被勾住，愿意看完、评论、甚至吵架，数据就起来。本 skill 把正向内容翻转成反向版本，并自动守住「不编、不替你定调、攻击观点不攻击人」等死规矩。

## 特点

- 覆盖三类反向角度：相反 / 反常识 / 冲突
- 内置 6 个公开案例打法 + 4 种心理学钩子
- 自带「防偷换清单」和「反向稿自检」护栏
- 不联网、不写稿也能用，跟抽母题、拆爆款、做内容方案的 skill 互补

## 怎么触发

对话里说以下任一句即可调用：

- 「反立场」「反过来写」「唱反调」「造个反向爆点」「把这条改成反着说」
- 给一个正向选题 / 正向稿，想要更强钩子
- 丢一条爆款，问「这条是不是用了反共识手法」

## 四种模式

| 模式 | 输入 | 输出 |
| --- | --- | --- |
| A 生成反向钩子 | 一个正向题 | 三类反向角度 + 钩子开头 + 套哪个打法 |
| B 正向稿改反向 | 一段正向稿 | 改成「先抛反调 → 反转 → 落观点」完整稿 |
| C 爆款反立场拆解 | 一条爆款 | 判断是否用了反立场 + 抽可复用骨架 |
| D 反向稿自检 | 一篇反向稿 | 三查（编没编 / 攻没攻人 / 有没依据）+ 修改建议 |

## 核心方法

**反向改写五步公式**：找共识立场 → 站到对面说反的 → 用真实依据撑住 → 钩子抛反调 → 收尾落观点。缺第 3 步（真实依据）＝空喊反调，必凉。

**六个打法**：反着行业来 / 主动露短板 / 大胆挑客户 / 颠覆身份结果 / 反向种草 / 小反转叙事。

## 边界（焊死）

1. 不替你定调：身份 / 定位 / 变现方向做参数，不预设
2. 不编造：只留"需填真实依据"占位符，绝不替编经历数据
3. 攻击观点不攻击人：涉及敏感对立（种族 / 性别 / 社会对立）直接拦下
4. 单案例 ≠ 普适：案例一律标注"公开报道，非保证"
5. 不把案例当保票：不承诺"必火"
